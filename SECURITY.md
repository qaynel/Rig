# Security Policy

## Supported versions

Security fixes land on the default branch and ship in the latest release.
Older releases are not maintained on separate security branches.

## Reporting a vulnerability

Report privately through [GitHub's vulnerability reporting form](https://github.com/qaynel/Rig/security/advisories/new).
GitHub private vulnerability reporting was verified enabled on 2026-10-27.
Do not submit a suspected vulnerability through a public issue, pull request,
or discussion.

Include a description, the version or commit
you tested, and steps to reproduce when you can share them without publishing
an exploit. The maintainers will reply through the private report.

## Scope

Reports about this repository and the published Rig installer are in scope.
A problem in a project that only consumes Rig should be reported to that
project, unless the defect is in Rig itself.
