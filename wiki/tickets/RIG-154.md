# RIG-154 — Fresh-checkout `npm test` fails: AT-HOME-1's fake npm needs a `rig-mcp/node_modules` tree nothing in the root run creates

**Class: TEST INFRASTRUCTURE / NON-HERMETIC FIXTURE.**
**Status: CLOSED (2026-08-31) — shipped in PR #140 / `a15d4267`, Gate-1 re-signed in the same commit; fresh-checkout `npm test` proof recorded.**
Ticket: RIG-154 on [[Tickets]].

## Problem

On a fresh local checkout `npm test` fails; CI passes. `tests/advanced-oracle.test.js`
case `AT-HOME-1` puts a fake `npm` on `PATH` whose fixture runs
`cp -R <root>/rig-mcp/node_modules <dest>` (`advanced-oracle.test.js:508`,
source path `:538`). Nothing in the root test run creates
`rig-mcp/node_modules` before that file executes — `node --test tests/*.test.js`
runs it *before* `npm test --prefix rig-mcp`, whose `pretest`
(`[ -d node_modules ] || npm install`) would. CI only passes because
`.github/workflows/test.yml:37-38` runs a standalone
`npm ci --prefix rig-mcp` first — a hidden ambient-state dependency invisible to
the test and to a fresh clone. Absent the tree, the `cp` fails, the fake npm
exits non-zero, `install.sh` aborts, and
`assert.equal(optedIn.status, 0)` (`:548`) fails.

Full mechanism, the two closed design decisions, and the frozen-surface analysis:
[[reasoning/2026-08-31-rig-154-fresh-checkout-npm-test-design.md]].

## Fix (shipped — PR #140 / `a15d4267`)

- **D1:** `package.json` `pretest` carries the brace-grouped guard:
  `{ <venv-guard>; } && { [ -d rig-mcp/node_modules ] || npm ci --prefix rig-mcp --no-audit --no-fund; }`.
  `wiki/gate1/package-scripts.json` updated to match; manifest digest refreshed.
- **D2:** `tests/rig-mcp-bootstrap.test.js` — two structural assertions
  (pretest guard present; CI carries no masking `npm ci --prefix rig-mcp` step).
- CI "Install bundled MCP runtime dependencies" step deleted.
- **Gate-1 re-sign: done in the same commit** by the human key holder —
  `gate1.sig` re-signed, `gate1.allowed-signers` moved to `ssh-ed25519`,
  `testing-infrastructure.manifest` + `package-scripts.json` updated.
  `node scripts/check-advanced-spec.js` → *Oracle verified: 5 files, 73
  acceptance cases*. The `--confirm-digest-delta 1408f38…` command in the
  original handoff described the pre-merge draft and must **not** be re-run.
