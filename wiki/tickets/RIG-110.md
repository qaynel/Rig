# RIG-110 — Prove first-wire + live-hook contracts for every supported host

**Status: DESIGNED — large verification program; scoped plan + partial defer.**
Ticket: RIG-110 on [[Tickets]].

## Problem
`host-coverage-spec §1` marks exact per-host live-hook contracts, complete
evidence bundles, and successful first wire as *pending for every executable
candidate*. §3.1 still carries unresolved conflicts: codewhale skills/MCP path
(`~/.deepseek/` vs `./.codewhale/`), hermes repo-scope, swival's missing
edit-time gate, Antigravity-CLI issue #60, and the community-only
`trigger: always_on` key. Serviceability is asserted, not verified.

## Findings
This is not a code defect — it is a **research + real-wire verification**
program across 19 hosts × 4 axes (live-hook, instruction, skills, MCP) + 6 CI
providers. §4 sets the evidence bar: vendor doc for the exact behavior,
vendor/version + date, fixtures + results, and first-wire evidence per
executable axis. Documentation cannot substitute for a first wire.

## Solution (bounded, tiered — beta cut vs full)
1. **Tier the matrix.** Split hosts into: (a) **verified-executable** (already
   have byte-landing tests + a real wire — keep), (b) **candidate** (contract
   drafted, no first wire — demote to pointer-only in the beta and label as such
   per §5 Slice A), (c) **pointer-only/unsupported** (record and emit nothing).
   Ship the beta on (a) + explicit (b/c) labeling; don't claim executable
   serviceability without a first wire.
2. **Resolve the §3.1 conflicts to a decided disposition each** (this part is
   finishable now, mostly documentation):
   - **codewhale**: pick `~/.deepseek/` vs `./.codewhale/` from current vendor
     docs; record with date. Until decided → user_global advisory only.
   - **hermes**: decide repo-scope; if unclear from docs → pointer-only.
   - **swival**: no edit-time gate → record as instruction/skills only, no
     enforcement claim.
   - **antigravity CLI**: issue #60 open → project-local MCP unsupported; use the
     [[RIG-105]] manual + verify path.
   - **`trigger: always_on`**: community-only key → do not depend on it; record.
3. **First-wire evidence** for each executable axis kept in tier (a): a fixture
   + result + dated wire log under `wiki/sources/`. New hosts enter tier (a) only
   with that bundle.

can draft and file for sign-off; the real first-wire runs need host access the
