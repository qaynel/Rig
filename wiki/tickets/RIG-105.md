# RIG-105 — Automate Antigravity MCP wiring or make the manual step first-class

**Status: APPROVED (2026-08-24) — surface manual step + verification check, not
auto-write. Not yet implemented.**
Ticket: RIG-105 on [[Tickets]].

## Decision
Owner approved the recommendation below. Implementation (onboarding copy-paste
block + `rig check --host antigravity` verification) is the next step;
revisit auto-write once upstream CLI issue #60 is resolved ([[RIG-110]]).

## Problem
`antigravity-plugin/mcp_config.json` ships `{"mcpServers": {}}` with a comment
telling users to hand-copy entries into `~/.gemini/config/mcp_config.json`.
Antigravity users get no automated MCP wiring (Tier B / PD-open-4). For a full
release this is either an automation gap or an onboarding gap.

## Findings
- `host-coverage-spec §3.2 †` records the Antigravity CLI-vs-IDE path split and
  the open CLI issue #60 (project-local MCP silently ignored). That split is why
  a blind automated write is risky: the CLI ignores the project file, and the
  IDE reads the user-global path.
- Onboarding already surfaces detected hosts and records writes in
  `.rig/install-manifest.jsonl`, so a "manual step with a verification check" fits
  the existing flow.

## Recommendation (make the manual step first-class)
Given issue #60, **do not** blind-write project-local MCP for Antigravity.
Instead:
1. Onboarding detects Antigravity and prints the **exact** copy-paste block for
   the chosen catalogue servers, targeted at `~/.gemini/config/mcp_config.json`
   (IDE) with the CLI caveat noted.
2. Add a **verification check** the user runs after pasting (e.g. `rig check
   --host antigravity` reads the user-global file and confirms the `rig` server
   is present), so the manual step has a closed loop rather than hope.
3. Record the decision in the wiki (supersedes the bare "template only"
   placeholder) and keep `mcp_config.json` as the documented template.

Automating the write becomes safe only once issue #60 is resolved upstream
([[RIG-110]] tracks that disposition); revisit then.

## Owner confirm (one line)
Approve "surface manual step + verification" over "auto-write" for the beta.
Recommended: yes — auto-write is unsafe while CLI issue #60 is open.
