## Problem

Install is sound — host filtering never fabricates trees for unselected hosts,
runtime/code never leaks into a default markdown install, journal CAS/third-state
is correct, and path containment is enforced everywhere (all confirmed). The
failure is on the other half of the promise: **a clean uninstall does not fully
reverse the install.** No test does a real install→uninstall roundtrip (every
lifecycle test feeds a synthetic manifest), so the whole cluster ships green.
Structural root cause (two uninstallers, no roundtrip test) is [[RIG-125]].

## Sub-findings (all leave orphans / incomplete reversal)

- **127.1 (Important) — `rig --uninstall` flag reverses almost nothing after a
  default install.** The flag path (`materialize.js:36-37` → `uninstall.js`)
  reads only the receipt and removes a fixed list. A plain markdown bootstrap
  writes no receipt, only `.rig/install-manifest.jsonl`, so routing/rules/skills/
  `.claude`/`.agents` trees/managed lines all remain. (Structural half in RIG-125.)
- **127.2 (Important) — non-purge uninstall deletes the journal even when files
  were retained best-effort** (`lifecycle.js:250-254`). A user-edited Rig file is
  correctly kept, but the manifest is then removed, so a second uninstall has no
  record to retry from — a permanent, record-less orphan.
- **127.3 (Important) — `--purge` leaves the install manifest on disk.** Manifest
  deletion lives only in the non-purge `else` branch (`lifecycle.js:246-255`), so
  the "more thorough" mode is inconsistent with its intent.
- **127.4 (Important, partially addressed 2026-08-25) — preimage backups are
  still write-only orphans.** The RIG-120 round-2 fix moved the store to
  `git rev-parse --git-path rig/preimages/<digest>` (fallback
  `.rig/preimages/` on non-git targets) so `git add -A` no longer stages
  credential-bearing bytes. They are still unjournaled, never read back, and
  not removed on uninstall. The committable-path half of this item is done;
  the reverse-install half is not.
- **127.5 (Important) — linked-worktree apply writes/renames the pre-commit hook
  un-journaled** (`apply.js:475-481`). The shared hooks dir is outside `target`;
  the user's `pre-commit` is renamed to `.rig-chained` and the shim written with
  plain fs, recording nothing. Uninstall (`lifecycle.js:193-204`) restores only
  from a manifest record, so the shim stays and the original hook is never
  restored — across every worktree.
- **127.6 (Important) — Rig-created instruction files left as empty orphans.**
  The `managed_line` uninstall branch strips the line and rewrites the file but
  never deletes it (`lifecycle.js:206-210`), even when Rig created it fresh via
  `ensure_line`; a clean uninstall leaves empty `AGENTS.md`/`GEMINI.md`/
  `.github/copilot-instructions.md`/`CLAUDE.md`.
- **127.7 (Minor) — emptied directories never removed** by the journal
  uninstaller (fabricated `.claude/skills/…`, `.agents/skills/…`, `.rig/` survive
  as empty trees). `uninstall.js` cleans `.rig`; the journal path has no
  equivalent.
- **127.8 (Major as of the 2026-08-25 receipt; was minor in the branch
  review) — a corrupted middle journal line is silently dropped**
  (`lifecycle.js` `readManifest`, `payload.js` journal parse). The
  `try/catch` meant for a truncated final line swallows any unparseable
  record. Its file is never reversed or reported. The independent receipt
  raised this as a **major**: damage is not verified to be only the final
  line.
- **127.9 (FIXED in the worktree, 2026-08-25, RIG-120 round-2) — missing
  `openclaw` CLI at uninstall no longer short-circuits ALL local removal.**
  `uninstall()` still sets `stopped` and `preservePrefixes` for an
  unremovable OpenClaw runtime, but the removal loop now runs; only paths
  under that prefix are skipped. Manifest/purge remain gated on `stopped`
  (that leftover is 127.2 / 127.3). Do not re-open 127.9 as if the whole-loop
  abort still exists.
- **127.10 (Minor) — legacy uninstaller hook-restore is worktree-blind**
  (`uninstall.js:18-22` hardcodes `.git/hooks/pre-commit`); `.rig/install-id`
  (`apply.js:33-42`, `openclaw-mcp.js:25-34`) is journaled and removed by
  neither uninstaller.

## Why it matters

"Clean uninstall" is a stated product property and a trust boundary: a user
must be able to fully remove Rig. As shipped, ordinary installs leave orphaned
preimages, empty instruction files, empty host trees, a leftover manifest under
`--purge`, and — in a worktree — a permanently hijacked pre-commit hook.

## Recommended direction

Route all removal through the single journal authority ([[RIG-125]]); journal the
preimage/hook/install-id writes so they are reversible; delete files Rig created
fresh when a managed strip empties them; rmdir emptied Rig dirs; delete the
manifest last in both modes; decouple the openclaw-CLI-absent case from local
removal. Gate with a real install→uninstall→"tree is clean" roundtrip test.

## Low-context implementation packet

**Outcome.** One public uninstall command reverses a real install, not a
synthetic list. It removes only Rig-owned bytes, restores a user hook when Rig
chained it, and retains the journal whenever any local removal is incomplete so
a second attempt can finish safely.

**Do not change.** Do not restore user-edited owned files over the user's bytes,
delete a manifest before all removals finish, treat a damaged middle journal
record as recoverable, or re-open the already-fixed OpenClaw whole-loop abort.
Do not test only `uninstall()` with an invented manifest; create at least one
install through the public entry point and remove it through the public entry
point.

**Implementation slices.**

1. Make the legacy `--uninstall` route to the journal lifecycle authority. The
   legacy receipt cleanup may become a compatibility shim, but it must not be a
   second source of removal semantics.
2. Record every write that has to be reversed: preimage stores, install-id, and
   both the original linked-worktree hook and Rig's shim. Use the existing
   journal record-before-mutate shape; never write an external hook with plain
   filesystem calls that bypass the journal.
3. Make journal parsing tolerate only a truncated final JSONL record. Any
   malformed non-final non-empty line must make uninstall refuse before deleting
   files and name the bad line.
4. During removal, delete a file created by `ensure_line` after stripping the
   managed line if nothing remains; remove empty Rig-created parents from the
   leaf upward. Restore the chained hook using the worktree-aware git hooks path.
5. Retain both manifest formats while `best_effort` is non-empty. Once every
   local entry is removed, delete the manifest last in both normal and purge
   modes. A purge additionally removes its allowed reports, never the evidence
   needed to retry a failed removal.

**Tests to write first.** Create `tests/install-uninstall-roundtrip.test.js`.
Use real temporary git repositories and the public materializer/bootstrap
commands for the first case. Snapshot only user-owned seed files; Rig-created
paths are expected to disappear.

| Test title | Setup | Required assertion |
|---|---|---|
| `public uninstall reverses a default bootstrap install` | Seed a repo with user `AGENTS.md`, run the default bootstrap, then invoke public `--uninstall` | User bytes equal the pre-install snapshot; no Rig rules, skills, routing, journal, or install-id remain. |
| `a retained user-edited file keeps the journal for retry` | Install, change a recorded owned file, uninstall normally | Status is best-effort, the file remains, and the journal remains. Restore/remove the conflicting byte, retry, and assert the journal is then gone. |
| `purge removes the manifest only after a clean removal` | Successful install and `uninstall --purge` | Reports allowed for purge and both manifest forms are absent only after all owned paths are gone. |
| `uninstall removes preimages empty instruction files and empty Rig directories` | Install records for a preimage and managed lines in otherwise empty instruction files | No preimage, empty instruction file, `.claude`/`.agents` skill tree, or empty `.rig` directory remains. |
| `linked-worktree uninstall restores the original pre-commit hook` | Main repo plus linked worktree with a user pre-commit hook | Applying in the worktree journals the external hook change; uninstall restores the exact original hook and removes the Rig shim/back-up. |
| `a corrupted middle journal record fails closed before removal` | Journal with valid record, malformed non-final line, valid record | Uninstall is non-zero, reports the malformed record, and neither recorded target is deleted. A truncated final line remains the only tolerated damage. |
| `missing OpenClaw tooling does not stop unrelated local removal` | Ledger with one unremovable OpenClaw entry plus local owned files | Result is best-effort for only that prefix; unrelated local paths are removed and the retained journal permits retry. |

## Acceptance

- The public uninstall command restores a default bootstrap install to the
  user's original bytes and removes Rig-owned artifacts.
  → `tests/install-uninstall-roundtrip.test.js::public uninstall reverses a default bootstrap install`
- A user-edited owned file is retained with its journal until a later retry can
  safely remove it.
  → `tests/install-uninstall-roundtrip.test.js::a retained user-edited file keeps the journal for retry`
- Purge removes either manifest only after clean local removal.
  → `tests/install-uninstall-roundtrip.test.js::purge removes the manifest only after a clean removal`
- Preimages, newly empty instruction files, and empty Rig-created directories
  do not remain as orphans.
  → `tests/install-uninstall-roundtrip.test.js::uninstall removes preimages empty instruction files and empty Rig directories`
- A linked-worktree install journals its shared hook changes, and public
  uninstall restores the exact user hook.
  → `tests/install-uninstall-roundtrip.test.js::linked-worktree uninstall restores the original pre-commit hook`
- A malformed non-final journal record refuses removal before deleting any
  recorded file.
  → `tests/install-uninstall-roundtrip.test.js::a corrupted middle journal record fails closed before removal`
- Missing OpenClaw tooling retains only that global entry and does not prevent
  unrelated local removal.
  → `tests/install-uninstall-roundtrip.test.js::missing OpenClaw tooling does not stop unrelated local removal`
