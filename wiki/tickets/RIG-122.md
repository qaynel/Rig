# RIG-122 — (Low priority) Offer the wiki-knowledge system as a Rig tool family

**Status: DECIDED (2026-08-24) — ship as optional markdown-only graft,
post-release. Not yet implemented; stays gated behind [[RIG-107]]/[[RIG-120]].**
Ticket: RIG-122 on [[Tickets]].

## Decision
Owner approved the recommendation below: pure markdown + conventions (no
Obsidian/Kanban runtime dependency), shipped as an optional graft after the
core runtime and release work land.

## Problem
Rig's own development runs on an Obsidian-based wiki — topic hubs, indexes,
reasoning traces, this Kanban board (`.obsidian/`, `kanban-plugin`). That
discipline is internal only; it isn't part of what Rig offers the repos it
installs into. Worth considering as an optional "family of tools" graft: a
starter wiki structure plus the convention for filing reasoning verbatim and
keeping topics in sync. Explicitly low priority, likely deferred until after the
core runtime ([[RIG-107]]) and release ([[RIG-120]]) work.

## The decision (one question for you)
Does the wiki system ship as an **optional Rig graft/skill family**, and if so
what is the minimum starter set?

## My recommendation: yes, but as pure markdown + conventions, post-release
- The valuable, portable part is the **convention**, not the app: `Home.md`
  entrypoint, `status.md`, topic hubs, `index/` (decisions/rejected/traps),
  `reasoning/` verbatim traces, and the "update the wiki in the same change"
  rule. All of that is plain markdown and satisfies the Tier 1 markdown-only
  constraint.
- Ship it as an **optional graft**: a starter `wiki/` skeleton (a handful of
  template files + a short conventions `SKILL.md`), no installed runtime, no sync
  engine, no required third-party app.
- **Obsidian/Kanban stay optional.** The `.obsidian/` bits are editor niceties
  (and are now gitignored here — their vendored plugin binaries tripped the
  secret scan). The structure must degrade to plain markdown without Obsidian —
  e.g. `Tickets.md` is a readable markdown board even without the kanban plugin.

## Why deferred
It's explicitly low priority and gated behind [[RIG-107]]/[[RIG-120]]. The
acceptance asks for a recorded decision; that's yours. Recommendation: defer to
post-beta, then ship the markdown-only convention graft. If you'd rather keep it
internal, I file the reasoning and close.
