# RIG-102 — Run the `rig-mcp` test suite in the CI gate

**Status: DEFERRED — needs owner re-sign (change is ready, cannot land alone).**
Ticket: RIG-102 on [[Tickets]].

## Problem
`npm test` never ran `npm test --prefix rig-mcp`, so the MCP server's shared
instruction contract could regress undetected.

## Findings (verified 2026-08-24)
- Acceptance bullet 3 is **already met**: `scripts/check-versions.js` already
  lists `rig-mcp/package.json` in `VERSION_FILES` (pinned 5.0.0).
- The rig-mcp suite runs standalone with **no external deps** — its test imports
  only `../instructions.js` → `hooks/rig-instructions.js` + `hooks/rig-config.js`
  (no `@modelcontextprotocol/sdk`). `npm test --prefix rig-mcp` = 3/3 pass.
- **Blocker:** `package.json` `scripts` are part of the *signed Gate 1 oracle*.
  `wiki/gate1/package-scripts.json` is a manifest entry in
  `wiki/gate1/testing-infrastructure.manifest`, whose digest is covered by
  `gate1.sig`. `scripts/check-advanced-spec.js` runs first in `npm test` and
  fails if `package.json.scripts` differ from that snapshot. So editing
  `test:code` trips the "agent cannot move its own goalpost" guard.

## Solution (ready — one line + owner re-sign)
The exact change:

```diff
- "test:code": "... && npm test --prefix pi-extension",
+ "test:code": "... && npm test --prefix pi-extension && npm test --prefix rig-mcp",
```

Landing requires the owner's re-signing ceremony (not delegable):
1. Apply the diff to `package.json`.
2. Mirror it in `wiki/gate1/package-scripts.json`.
3. Recompute that file's sha256 and update its line in
   `wiki/gate1/testing-infrastructure.manifest`.
4. Re-sign the oracle: `ssh-keygen -Y sign -n rig-gate1 -f <owner-key>` over the
   `rig-oracle-freeze-v2` message → `wiki/gate1/gate1.sig`.
5. `npm test` — `check-advanced-spec.js` verifies the new signature and the
   rig-mcp suite now gates every push.

I verified the suite passes and reverted `package.json` so the branch stays
green until the ceremony. (A deliberately broken rig-mcp change then fails
`npm test`, satisfying acceptance bullet 2.)
