# Rebuild acceptance criteria (unsigned draft)

Each outcome names the observable result exercised by its one proving test. These criteria remain unsigned until the owner sitting.

| Criterion | Requirement | Outcome |
|---|---|---|
| AC-RB-BENCH-1 | RB-BENCH-1 | committed benchmark split has a seed, disjoint partitions, and all 89 tasks. |
| AC-RB-BENCH-2 | RB-BENCH-2 | planted hidden-test tampering is reported as tampered and failed. |
| AC-RB-BENCH-3 | RB-BENCH-3 | report applies every match condition to fixture session data. |
| AC-RB-BENCH-4 | RB-BENCH-4 | plain arm selects no Rig reference and writes no .rig directory. |
| AC-RB-BENCH-5 | RB-BENCH-5 | at least 30 vague-intent tasks keep grading tests outside agent-visible files. |
| AC-RB-BENCH-6 | RB-BENCH-6 | a filename-only gain fails the counterfactual robustness check. |
| AC-RB-BENCH-7 | RB-BENCH-7 | test split cannot run during tuning and final scoring is single-use. |
| AC-RB-BENCH-8 | RB-BENCH-8 | every tuning decision carries its floor candidate. |
| AC-RB-BENCH-9 | RB-BENCH-9 | benchmark arms contain all three model ladder comparisons. |
| AC-RB-BENCH-10 | RB-BENCH-10 | fit input tokens contribute to measured session cost. |
| AC-RB-BENCH-11 | RB-BENCH-11 | report includes tokens, tampering, source lines and human interventions. |
| AC-RB-BENCH-12 | RB-BENCH-12 | published result uses a passing ladder step or the closest measured step. |
| AC-RB-BENCH-13 | RB-BENCH-13 | untouched test split is scored once and SkillsBench remains held back. |
| AC-RB-BENCH-14 | RB-BENCH-14 | tuning stops after three non-improving rounds or the release date. |
| AC-RB-BENCH-15 | RB-BENCH-15 | benchmark runner completes three paired runs per task and arm. |
| AC-RB-BENCH-16 | RB-BENCH-16 | comparison raw sessions use pinned models and one common window. |
| AC-RB-BENCH-17 | RB-BENCH-17 | Sonnet benchmark includes one ablation arm per mapped role. |
| AC-RB-CAT-1 | RB-CAT-1 | each mapped role has one complete plain-language catalogue entry. |
| AC-RB-CAT-2 | RB-CAT-2 | every catalogue piece path exists in the applied overlay output. |
| AC-RB-CAT-3 | RB-CAT-3 | inspect-repo reports dependency and existing harness facts without decisions. |
| AC-RB-CAT-4 | RB-CAT-4 | inspect-repo makes no outbound network request. |
| AC-RB-CAT-5 | RB-CAT-5 | first-session report has an outcome and recommendation for every role question. |
| AC-RB-COORD-1 | RB-COORD-1 | each active role trigger routes to one matching role. |
| AC-RB-COORD-2 | RB-COORD-2 | unmatched situations use general fallback and matched ones do not. |
| AC-RB-COORD-3 | RB-COORD-3 | lock safety wins a conflicting upstream trigger and is written first. |
| AC-RB-COORD-4 | RB-COORD-4 | profile cannot disable locked tests and the refusal is logged. |
| AC-RB-COORD-5 | RB-COORD-5 | startup returns one ordered instruction sequence despite multiple upstream hooks. |
| AC-RB-COORD-6 | RB-COORD-6 | bounded delegation selects the cheaper available model or stays inline when unsupported. |
| AC-RB-DOOR-1 | RB-DOOR-1 | proposing a first-session fit writes nothing to host install targets. |
| AC-RB-DOOR-2 | RB-DOOR-2 | generated first-session questions recommend outcomes and accept the proposed answer. |
| AC-RB-DOOR-3 | RB-DOOR-3 | sign-off interview requires an explicit selection before install. |
| AC-RB-DOOR-4 | RB-DOOR-4 | marketplace and shell routes produce the same installed tree for one fit. |
| AC-RB-FETCH-1 | RB-FETCH-1 | fresh install succeeds while outbound sockets are blocked. |
| AC-RB-FETCH-2 | RB-FETCH-2 | installed .rig contains no fetched-upstream state or metadata. |
| AC-RB-FETCH-3 | RB-FETCH-3 | no payload module supports fetching upstreams during setup. |
| AC-RB-FETCH-4 | RB-FETCH-4 | source, scripts, and tests contain no old fetch module references. |
| AC-RB-FIT-1 | RB-FIT-1 | a fit above the byte budget is rejected with BUDGET. |
| AC-RB-FIT-2 | RB-FIT-2 | active roles with a user-edited shared trigger fail and name both roles. |
| AC-RB-FIT-3 | RB-FIT-3 | dormant roles are absent from host targets and their hooks do not run at startup. |
| AC-RB-FIT-4 | RB-FIT-4 | an existing harness skill remains the sole discoverable copy. |
| AC-RB-FIT-5 | RB-FIT-5 | repository growth proposes UI and browser roles, then approved fit matches fresh fit. |
| AC-RB-FIT-6 | RB-FIT-6 | removing dormant files leaves a valid fit. |
| AC-RB-FIT-7 | RB-FIT-7 | uninstalling one graft preserves other Rig roles and user files. |
| AC-RB-FIT-8 | RB-FIT-8 | the web-UI refit benchmark task passes hidden tests at least as often as fresh fit. |
| AC-RB-FIT-9 | RB-FIT-9 | an overlay-created trigger overlap is rejected with TRIGGER_OVERLAP. |
| AC-RB-FIT-10 | RB-FIT-10 | locally edited installed skill bytes are retained and reported. |
| AC-RB-FIT-11 | RB-FIT-11 | the fit validator reports missing active capability facts. |
| AC-RB-FIT-12 | RB-FIT-12 | approved refit materializes the same active role tree as a fresh fit. |
| AC-RB-FIT-13 | RB-FIT-13 | changed proposal digest refuses before altering installed files. |

| AC-RB-LOCK-1 | RB-LOCK-1 | an installed repository refuses edits to a locked test and names the path. |
| AC-RB-LOCK-2 | RB-LOCK-2 | mutation score below 70 percent blocks locking. |
| AC-RB-LOCK-3 | RB-LOCK-3 | missing mutation tooling is a named gap and fails closed. |
| AC-RB-LOCK-4 | RB-LOCK-4 | passwordless sudo is detected but never counts as user approval. |
| AC-RB-LOCK-5 | RB-LOCK-5 | sudo probe is non-interactive when a password is required. |
| AC-RB-MEM-1 | RB-MEM-1 | memory recall finds a meaning match with networking disabled and no model download. |
| AC-RB-MEM-2 | RB-MEM-2 | active view stays within 8 KB after 1,000 writes. |
| AC-RB-MEM-3 | RB-MEM-3 | memory benchmark report compares pass rate and solved-task cost with intervals. |
| AC-RB-MEM-4 | RB-MEM-4 | memory role changes only when its full result interval beats the incumbent. |
| AC-RB-OVL-1 | RB-OVL-1 | all overlays apply cleanly and preserve pinned upstream bytes. |
| AC-RB-OVL-2 | RB-OVL-2 | changed patched context names exactly the failing patch and source file. |

| AC-RB-OVL-4 | RB-OVL-4 | every pinned file matches its lock digest. |
| AC-RB-POL-1 | RB-POL-1 | decision prose without a wiki pointer fails with a line number and current CLAUDE passes. |

| AC-RB-POL-3 | RB-POL-3 | policy flags technical confirmation wording and accepts a plain recommendation. |
