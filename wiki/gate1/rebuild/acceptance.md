# Rebuild acceptance criteria (unsigned draft)

Each outcome names the observable result exercised by its one proving test. These criteria remain unsigned until the owner sitting.

| Criterion | Requirement | Outcome |
|---|---|---|
| AC-RB-BENCH-1 | RB-BENCH-1 | committed benchmark split has a seed, disjoint partitions, and all 89 tasks. |
| AC-RB-BENCH-2 | RB-BENCH-2 | planted hidden-test tampering is reported as tampered and failed. |
| AC-RB-BENCH-3 | RB-BENCH-3 | report applies every match condition to fixture session data. |
| AC-RB-BENCH-4 | RB-BENCH-4 | plain arm selects no Rig reference and writes no .rig directory. |
| AC-RB-BENCH-5 | RB-BENCH-5 | at least 30 vague-intent tasks keep grading tests outside agent-visible files. |
| AC-RB-BENCH-6 | RB-BENCH-6 | a filename-only gain fails the counterfactual robustness check. |
| AC-RB-BENCH-7 | RB-BENCH-7 | test split cannot run during tuning and final scoring is single-use. |
| AC-RB-BENCH-8 | RB-BENCH-8 | every tuning decision carries its floor candidate. |
| AC-RB-BENCH-9 | RB-BENCH-9 | benchmark arms contain all three model ladder comparisons. |
| AC-RB-BENCH-10 | RB-BENCH-10 | fit input tokens contribute to measured session cost. |
| AC-RB-BENCH-11 | RB-BENCH-11 | report includes tokens, tampering, source lines and human interventions. |
| AC-RB-BENCH-12 | RB-BENCH-12 | published result uses a passing ladder step or the closest measured step. |
| AC-RB-BENCH-13 | RB-BENCH-13 | untouched test split is scored once and SkillsBench remains held back. |
| AC-RB-BENCH-14 | RB-BENCH-14 | tuning stops after three non-improving rounds or the release date. |
| AC-RB-BENCH-15 | RB-BENCH-15 | benchmark runner completes three paired runs per task and arm. |
| AC-RB-BENCH-16 | RB-BENCH-16 | comparison raw sessions use pinned models and one common window. |
| AC-RB-BENCH-17 | RB-BENCH-17 | Sonnet benchmark includes one ablation arm per mapped role. |
| AC-RB-CAT-1 | RB-CAT-1 | each mapped role has one complete plain-language catalogue entry. |
| AC-RB-CAT-2 | RB-CAT-2 | every catalogue piece path exists in the applied overlay output. |
| AC-RB-CAT-3 | RB-CAT-3 | inspect-repo reports dependency and existing harness facts without decisions. |
| AC-RB-CAT-4 | RB-CAT-4 | inspect-repo makes no outbound network request. |
| AC-RB-CAT-5 | RB-CAT-5 | first-session report has an outcome and recommendation for every role question. |
| AC-RB-COORD-1 | RB-COORD-1 | each active role trigger routes to one matching role. |

| AC-RB-COORD-5 | RB-COORD-5 | startup returns one ordered instruction sequence despite multiple upstream hooks. |

| AC-RB-DOOR-1 | RB-DOOR-1 | proposing a first-session fit writes nothing to host install targets. |

| AC-RB-FIT-1 | RB-FIT-1 | a fit above the byte budget is rejected with BUDGET. |
