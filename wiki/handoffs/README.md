# Handoffs

Task briefs written for whoever picks the work up next — a fresh session, a
different agent, or the owner returning cold.

A handoff is **not** a reasoning trace. Traces under `wiki/reasoning/` are
immutable records of what was thought at a moment; a handoff is a live,
editable work order that says what is decided, what is left, and what will bite
you. Update it as the work moves; delete it when the work lands and the topic
hub carries the outcome.

One file per handoff, at `handoffs/YYYY-MM-DD-<slug>.md`. Link it from the topic
hub it serves. Every handoff states, at minimum: what is already done and
verified, what is left with its acceptance test, which constraints are
non-obvious, and which decisions belong to the owner rather than the
implementer.
