# Controlled improvement and memory consolidation

PROPOSED. The system learns from completed work without turning every routine lesson into an owner approval. It cannot grade or relax its own protected oracle. No numeric quality target substitutes for real acceptance evidence.

## Authority by surface

| Surface | Automatic agent action | Boundary |
|---|---|---|
| Scoped memory, preferences and run notes | Add, correct with provenance, merge duplicates, mark stale, retain negative outcomes | Keep source and scope; imported/retrieved text is data; never convert a memory entry into an instruction or permission. Owner can correct or remove an ordinary preference. |
| Safe local check and fixture | Draft, run historical replay and full gate, land when it cannot alter signed acceptance/policy/security or release authority | Independent, fixed regression oracle; record before/after evidence and rollback path. A failing or ambiguous replay leaves it as a candidate. |
| Skills, routing, model policy, security and trust controls | Draft proposed change only | Protected change requires existing owner authority through the one Gate 1 key; no second approval credential. |
| Gate 1 requirements, acceptance, manifested tests | Propose correction only | Owner edits/re-signs through existing Gate 1 path. No agent write to frozen files. |
| Evaluator, validation rules, release checks | Propose only | Improvement code has no write path to the evaluator that judges it. Protected change uses owner authority. |
| Publish, push or deploy | Prepare evidence | User authorization and existing release gates. |

Safe check promotion is **automatic only when its effect is bounded to an unprotected local prevention check** and replay proves it has no acceptance/policy/security effect. If the classification is uncertain, the check remains a candidate. The signed oracle cannot be weakened by adding a check, and no automatic check may cause a release pass by changing the evaluator.

## Learning loop

1. Record review findings, phase failures and repeated owner instructions with normalized keys and source IDs. Exact/near-exact matching is deterministic; a heuristic's ceiling is false negatives and its upgrade path is provenance-aware semantic grouping that still requires replay.
2. On the second occurrence, generate one candidate with both examples, a failing fixture and the expected prevented behavior. No candidate is generated from a lone noisy event.
3. Run the fixture against before/after code, replay historical positives and known negatives, and run the unchanged full gate. Include a baseline/no-change option. A fabricated pass, missed triggering example, false positive or regression rejects the candidate.
4. Persist `helped`, `hurt`, `no observed effect` or `confounded`, including failures and why. Do not repeatedly propose a rejected idea without new evidence.
5. Promote a bounded safe check automatically with an attributed change record. Present protected proposals to the owner with the exact consequence and the existing key path. Remove a recurring item from the 8 KB view only after its deeper record and resulting check remain linked and retrievable.

The local review state machine already carries finding classes across rounds and uses positive evidence before charging a review authorization. That code is uncommitted. The broader learning loop is a proposal, not shipped behavior.

## Automatic wiki and memory compaction

The three-minute dated reasoning trace cadence stays in force. At a deterministic close-out or index maintenance point, classify records as **hot** (current decision, active run and unresolved gap), **warm** (recent supporting explanation), or **cold** (completed immutable source). Compaction changes frontmatter/index/projections, never trace bodies. Before moving anything out of the active view, compare a generated decision/source manifest before and after: every owner ruling, source link, negative lesson and protected evidence must still resolve and yield the same answer to reference queries. If the fidelity check fails, keep the original hot state and report the failing pointers. The 8 KB cap applies only to the rendered active view, not storage.

Use local deterministic metadata indexing and summarisation first. A model-assisted summary is optional, bounded, verified against its source IDs and never authoritative. No daemon or automatic paid call is required. The shipped local semantic index supports memory discovery offline; cited lexical fallback and explicit provenance remain mandatory.

## Non-negotiable regression cases

Adversarial proposals that edit Gate 1, trust material, security controls, evaluator rules, or their own checks are refused. A good candidate that the baseline already passes is rejected as redundant. A candidate that catches its two triggers but breaks a known good case is rejected. An interrupted graduation resumes once, without duplicate check or authorization. Compaction preserves exact signed bytes and immutable trace bodies. These are runnable acceptance checks before any improvement path is enabled.
