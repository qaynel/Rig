findings.

   release blocker and Slice 14 was not release-blocking. If "red" meant a
   failing code-test exit for all 114 non-release leaves, D23's specification
   gate exception would only move the deadlock from the spec gate to the code
   gate. The correction keeps the red state but makes it a catalogue status and
   future-support/complete-catalogue blocker, not a lint-format release failure.

   post-implementation review could change the document to `FROZEN`. The
   correction points freeze to §17.1 and makes Slice 15 release evidence only;
   freeze happens once, before implementation.

   holding a valid credential cannot self-appoint a recovery key. Per D19, the
   signature artifact cannot prove the key class or the user's hardware touch.
   The correction keeps the product ceremony but narrows executable evidence to
   what automation can prove: pre-loss registration, fingerprint/namespace
   distinctness, receipt validity, recovery exhaustion, recovery side effects,
   and declared-class disclosure.
