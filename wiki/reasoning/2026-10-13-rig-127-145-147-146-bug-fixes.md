## RIG-127.12 (commit bdc2f21a)

- Red: with a nameless legacy record plus a second `rig:*` block, the wildcard
  regex stripped both.
- Green + ruling: a legacy record carries no block name and no block digest,
  only the file-level `preimage_digest`/`digest`. So a nameless record strips a
  block only when removing exactly that block reproduces the journaled
  `preimage_digest` (or empties a file the record created). Anything else is
  best-effort and the file is untouched. Consequence: a second `rig:*` block
  added to the file after Rig's write is not attributable, so that file goes
  best-effort rather than being partly stripped. Named-block records unchanged.
