# Gate 2 v0.12 retraces the approved D24 one-gate oracle

The owner-approved Gate 1 amendment changes five load-bearing technical
boundaries. The working design now signs business intent, acceptance, and a
stable testing-infrastructure manifest under one v2 message; Gate 2 is present
but never frozen. D24 restores the authored-service check to all 115 leaves at
declared Policy grade, activates only detected or explicitly selected host
trees, requires every physically vendored skill in distribution, and makes the
named-tag `5.0.0` path part of the complete release.

The repository audit found 55 `SKILL.md` packages in both commit `ff7cea5` and
the matching upstream release, not the 56 stated in the original D24 trace.
The working design uses the observable intent — every vendored skill — and
records 55 as the inventory-backed count. No nonexistent extra skill is
invented to satisfy a stale number.

The oracle verifier owns integrity and target coverage, not a pre-
implementation false green. It verifies the owner signature and every
manifested test byte before code tests, checks one present technical approach,
and checks exact equality between the 68 Gate 1 IDs, trace rows, and real test
titles. The manifested product targets may then fail for named missing behavior
until implementation clears them without changing their bytes.
