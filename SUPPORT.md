# Support

## Questions

Read the [README](README.md) and the [installation guide](docs/install.md),
then search [existing issues](https://github.com/qaynel/Rig/issues). If the
answer is not there, open a GitHub issue and describe what you already tried.

## Bugs and changes

Use the issue templates for bugs and feature requests. Code changes follow
[CONTRIBUTING.md](CONTRIBUTING.md).

## Security

Do not report a vulnerability in a public issue. Use
[SECURITY.md](SECURITY.md).

## Conduct

Report unacceptable behavior as described in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Accessibility

Report barriers as described in [ACCESSIBILITY.md](ACCESSIBILITY.md).
