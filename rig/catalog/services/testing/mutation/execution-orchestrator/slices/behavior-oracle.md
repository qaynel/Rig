# testing.mutation.execution-orchestrator - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming execution orchestrator result from a real policy violation. It activates `execution-orchestrator-source-code-boundary`, `execution-orchestrator-mutation-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
