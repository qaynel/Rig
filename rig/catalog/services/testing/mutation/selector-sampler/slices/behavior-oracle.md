# testing.mutation.selector-sampler - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming selector sampler result from a real policy violation. It activates `selector-sampler-source-code-boundary`, `selector-sampler-mutation-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
