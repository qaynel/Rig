# testing.mutation.run-reporting - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `mutation.run-reporting` and prevents none from being silently absorbed. It activates `run-reporting-source-code-boundary`, `run-reporting-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
