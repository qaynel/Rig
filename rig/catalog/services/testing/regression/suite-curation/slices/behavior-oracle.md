# testing.regression.suite-curation - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming suite curation result from a real policy violation. It activates `suite-curation-source-code-boundary`, `suite-curation-regression-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
