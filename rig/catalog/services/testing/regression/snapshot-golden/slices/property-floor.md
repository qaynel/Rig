# testing.regression.snapshot-golden - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `regression.snapshot-golden` and prevents none from being silently absorbed. It activates `snapshot-golden-source-code-boundary`, `snapshot-golden-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
