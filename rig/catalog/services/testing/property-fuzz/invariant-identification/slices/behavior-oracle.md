# testing.property-fuzz.invariant-identification - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming invariant identification result from a real policy violation. It activates `invariant-identification-source-code-boundary`, `invariant-identification-property-fuzz-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
