# testing.performance-load.perf-regression-ci - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming perf regression ci result from a real policy violation. It activates `perf-regression-ci-source-code-boundary`, `perf-regression-ci-performance-load-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
