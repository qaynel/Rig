# testing.performance-load.load-stress-scripts - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `perf-load-test-authoring`, `load-stress-scripts` and prevents none from being silently absorbed. It activates `load-stress-scripts-source-code-boundary`, `load-stress-scripts-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
