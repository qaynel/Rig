# testing.performance-load.benchmarks - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming benchmarks result from a real policy violation. It activates `benchmarks-source-code-boundary`, `benchmarks-performance-load-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
