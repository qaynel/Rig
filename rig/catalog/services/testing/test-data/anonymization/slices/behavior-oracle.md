# testing.test-data.anonymization - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming anonymization result from a real policy violation. It activates `anonymization-source-code-boundary`, `anonymization-test-data-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
