# testing.test-data.fixtures-factories - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `test-data.fixtures-factories` and prevents none from being silently absorbed. It activates `fixtures-factories-source-code-boundary`, `fixtures-factories-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
