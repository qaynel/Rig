# testing.test-data.fixtures-factories - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming fixtures factories result from a real policy violation. It activates `fixtures-factories-source-code-boundary`, `fixtures-factories-test-data-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
