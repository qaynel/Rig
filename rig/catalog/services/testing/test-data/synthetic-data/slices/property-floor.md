# testing.test-data.synthetic-data - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `test-data.synthetic-data` and prevents none from being silently absorbed. It activates `synthetic-data-source-code-boundary`, `synthetic-data-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
