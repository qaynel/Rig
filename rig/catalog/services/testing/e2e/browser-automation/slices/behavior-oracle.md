# testing.e2e.browser-automation - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming browser automation result from a real policy violation. It activates `browser-automation-source-code-boundary`, `browser-automation-e2e-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
