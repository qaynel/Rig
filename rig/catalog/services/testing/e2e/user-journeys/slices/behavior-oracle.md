# testing.e2e.user-journeys - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming user journeys result from a real policy violation. It activates `user-journeys-source-code-boundary`, `user-journeys-e2e-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
