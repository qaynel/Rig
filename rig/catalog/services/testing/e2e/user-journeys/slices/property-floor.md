# testing.e2e.user-journeys - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `e2e.user-journeys` and prevents none from being silently absorbed. It activates `user-journeys-source-code-boundary`, `user-journeys-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
