# testing.unit.test-case-generation - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming test case generation result from a real policy violation. It activates `test-case-generation-source-code-boundary`, `test-case-generation-unit-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
