# testing.unit.test-case-generation - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `unit.test-case-generation` and prevents none from being silently absorbed. It activates `test-case-generation-source-code-boundary`, `test-case-generation-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
