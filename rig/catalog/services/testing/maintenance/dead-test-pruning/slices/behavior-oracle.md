# testing.maintenance.dead-test-pruning - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming dead test pruning result from a real policy violation. It activates `dead-test-pruning-source-code-boundary`, `dead-test-pruning-maintenance-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
