# testing.maintenance.test-code-sync - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming test code sync result from a real policy violation. It activates `test-code-sync-source-code-boundary`, `test-code-sync-maintenance-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
