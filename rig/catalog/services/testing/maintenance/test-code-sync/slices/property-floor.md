# testing.maintenance.test-code-sync - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `maintenance.test-code-sync` and prevents none from being silently absorbed. It activates `test-code-sync-source-code-boundary`, `test-code-sync-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
