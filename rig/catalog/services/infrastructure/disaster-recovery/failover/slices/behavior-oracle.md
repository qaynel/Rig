# infrastructure.disaster-recovery.failover - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming failover result from a real policy violation. It activates `failover-source-code-boundary`, `failover-disaster-recovery-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
