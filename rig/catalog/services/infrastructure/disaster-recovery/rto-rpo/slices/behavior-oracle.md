# infrastructure.disaster-recovery.rto-rpo - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming rto rpo result from a real policy violation. It activates `rto-rpo-source-code-boundary`, `rto-rpo-disaster-recovery-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
