# infrastructure.disaster-recovery.dr-runbooks - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming dr runbooks result from a real policy violation. It activates `dr-runbooks-source-code-boundary`, `dr-runbooks-disaster-recovery-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
