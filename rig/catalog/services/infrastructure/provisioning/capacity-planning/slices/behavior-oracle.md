# infrastructure.provisioning.capacity-planning - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming capacity planning result from a real policy violation. It activates `capacity-planning-source-code-boundary`, `capacity-planning-provisioning-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
