# infrastructure.provisioning.environment-parity - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming environment parity result from a real policy violation. It activates `environment-parity-source-code-boundary`, `environment-parity-provisioning-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
