# infrastructure.cicd.deployment-strategy - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming deployment strategy result from a real policy violation. It activates `deployment-strategy-source-code-boundary`, `deployment-strategy-cicd-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
