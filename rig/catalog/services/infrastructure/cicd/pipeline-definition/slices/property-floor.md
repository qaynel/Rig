# infrastructure.cicd.pipeline-definition - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `cicd.pipeline-definition` and prevents none from being silently absorbed. It activates `pipeline-definition-source-code-boundary`, `pipeline-definition-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
