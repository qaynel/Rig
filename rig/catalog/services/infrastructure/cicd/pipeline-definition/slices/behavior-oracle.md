# infrastructure.cicd.pipeline-definition - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming pipeline definition result from a real policy violation. It activates `pipeline-definition-source-code-boundary`, `pipeline-definition-cicd-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
