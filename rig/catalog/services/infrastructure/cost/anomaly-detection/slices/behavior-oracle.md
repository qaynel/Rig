# infrastructure.cost.anomaly-detection - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming anomaly detection result from a real policy violation. It activates `anomaly-detection-source-code-boundary`, `anomaly-detection-cost-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
