# infrastructure.cost.utilization-analysis - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming utilization analysis result from a real policy violation. It activates `utilization-analysis-source-code-boundary`, `utilization-analysis-cost-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
