# infrastructure.networking.vpc-firewall - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming vpc firewall result from a real policy violation. It activates `vpc-firewall-source-code-boundary`, `vpc-firewall-networking-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
