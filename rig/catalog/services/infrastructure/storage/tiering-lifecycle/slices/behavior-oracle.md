# infrastructure.storage.tiering-lifecycle - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming tiering lifecycle result from a real policy violation. It activates `tiering-lifecycle-source-code-boundary`, `tiering-lifecycle-storage-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
