# infrastructure.storage.db-provisioning - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming db provisioning result from a real policy violation. It activates `db-provisioning-source-code-boundary`, `db-provisioning-storage-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
