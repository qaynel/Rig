# infrastructure.observability.metrics-dashboards - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming metrics dashboards result from a real policy violation. It activates `metrics-dashboards-source-code-boundary`, `metrics-dashboards-observability-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
