# infrastructure.scaling-reliability.autoscaling - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming autoscaling result from a real policy violation. It activates `autoscaling-source-code-boundary`, `autoscaling-scaling-reliability-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
