# infrastructure.environment-config.feature-flags - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming feature flags result from a real policy violation. It activates `feature-flags-source-code-boundary`, `feature-flags-environment-config-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
