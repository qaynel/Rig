# infrastructure.environment-config.mcp-compatibility - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming mcp compatibility result from a real policy violation. It activates `mcp-compatibility-source-code-boundary`, `mcp-compatibility-environment-config-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
