# infrastructure.environment-config.mcp-compatibility - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `environment-config.mcp-compatibility` and prevents none from being silently absorbed. It activates `mcp-compatibility-source-code-boundary`, `mcp-compatibility-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
