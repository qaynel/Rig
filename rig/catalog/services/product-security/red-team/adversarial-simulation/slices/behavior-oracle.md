# product-security.red-team.adversarial-simulation - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming adversarial simulation result from a real policy violation. It activates `adversarial-simulation-source-code-boundary`, `adversarial-simulation-red-team-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
