# product-security.license-compliance.license-diff - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `license-compliance.license-diff` and prevents none from being silently absorbed. It activates `license-diff-source-code-boundary`, `license-diff-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
