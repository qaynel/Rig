# product-security.license-compliance.license-diff - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming license diff result from a real policy violation. It activates `license-diff-source-code-boundary`, `license-diff-license-compliance-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
