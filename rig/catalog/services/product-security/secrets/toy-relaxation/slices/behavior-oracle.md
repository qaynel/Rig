# product-security.secrets.toy-relaxation - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming toy relaxation result from a real policy violation. It activates `toy-relaxation-source-code-boundary`, `toy-relaxation-secrets-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
