# development.data-schema.db-migrations - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming db migrations result from a real policy violation. It activates `db-migrations-source-code-boundary`, `db-migrations-data-schema-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
