# development.code-creation.codegen-scaffolding - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `code-creation.codegen-scaffolding` and prevents none from being silently absorbed. It activates `codegen-scaffolding-source-code-boundary`, `codegen-scaffolding-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
