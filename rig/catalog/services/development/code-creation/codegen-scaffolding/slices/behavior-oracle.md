# development.code-creation.codegen-scaffolding - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming codegen scaffolding result from a real policy violation. It activates `codegen-scaffolding-source-code-boundary`, `codegen-scaffolding-code-creation-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
