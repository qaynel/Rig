# development.code-creation.refactoring - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `code-creation.refactoring` and prevents none from being silently absorbed. It activates `refactoring-source-code-boundary`, `refactoring-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
