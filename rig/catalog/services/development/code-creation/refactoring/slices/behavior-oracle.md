# development.code-creation.refactoring - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming refactoring result from a real policy violation. It activates `refactoring-source-code-boundary`, `refactoring-code-creation-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
