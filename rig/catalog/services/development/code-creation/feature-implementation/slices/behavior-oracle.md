# development.code-creation.feature-implementation - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming feature implementation result from a real policy violation. It activates `feature-implementation-source-code-boundary`, `feature-implementation-code-creation-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
