# development.code-creation.feature-implementation - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `code-creation.feature-implementation` and prevents none from being silently absorbed. It activates `feature-implementation-source-code-boundary`, `feature-implementation-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
