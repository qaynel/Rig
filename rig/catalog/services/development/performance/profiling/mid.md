# development.performance.profiling - mid

Grade: mid (Context target). Until the named local evidence is wired, assurance remains Policy-grade generic baseline practice rather than repository-tailored coverage.

After the minimal boundary passes, `profiling-performance-context` evaluates `code-profiling`, `bottleneck-identification`. Given code-profiling has a repository-specific convention and evidence source, it passes only when the result names the consulted path or command and excludes an adjacent performance concern; it fails when the result infers local convention without an inspectable source. The target is `fixture:development.performance.profiling:repository-context`, and adjacent performance ownership stays outside the verdict.
