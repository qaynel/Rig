# development.repo-hygiene.issue-pr-triage - slice floor + mutation-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `floor` and `mutation-floor` slice establishes the lowest non-vacuous issue pr triage verdict for `source-code`. It activates `issue-pr-triage-source-code-boundary` and reports a named coverage gap when its repository binding or required dependency is unavailable.
