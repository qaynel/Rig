# development.repo-hygiene.issue-pr-triage - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming issue pr triage result from a real policy violation. It activates `issue-pr-triage-source-code-boundary`, `issue-pr-triage-repo-hygiene-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
