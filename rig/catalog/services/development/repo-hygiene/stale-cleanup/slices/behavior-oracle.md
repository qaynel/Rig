# development.repo-hygiene.stale-cleanup - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming stale cleanup result from a real policy violation. It activates `stale-cleanup-source-code-boundary`, `stale-cleanup-repo-hygiene-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
