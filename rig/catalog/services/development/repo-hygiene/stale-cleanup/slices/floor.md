# development.repo-hygiene.stale-cleanup - slice floor + mutation-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `floor` and `mutation-floor` slice establishes the lowest non-vacuous stale cleanup verdict for `source-code`. It activates `stale-cleanup-source-code-boundary` and reports a named coverage gap when its repository binding or required dependency is unavailable.
