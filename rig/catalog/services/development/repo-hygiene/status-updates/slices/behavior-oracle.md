# development.repo-hygiene.status-updates - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming status updates result from a real policy violation. It activates `status-updates-source-code-boundary`, `status-updates-repo-hygiene-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
