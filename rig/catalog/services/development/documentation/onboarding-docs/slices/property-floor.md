# development.documentation.onboarding-docs - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `documentation.onboarding-docs` and prevents none from being silently absorbed. It activates `onboarding-docs-source-code-boundary`, `onboarding-docs-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
