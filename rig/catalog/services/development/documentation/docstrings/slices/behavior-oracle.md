# development.documentation.docstrings - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming docstrings result from a real policy violation. It activates `docstrings-source-code-boundary`, `docstrings-documentation-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
