# development.code-quality.code-review - slice property-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `property-floor` slice holds ownership at `code-quality.code-review` and prevents none from being silently absorbed. It activates `code-review-source-code-boundary`, `code-review-evidence-receipt` and reports a named coverage gap when its repository binding or required dependency is unavailable.
