# development.dependency-management.upgrades-migration - slice floor + mutation-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `floor` and `mutation-floor` slice establishes the lowest non-vacuous upgrades migration verdict for `source-code`. It activates `upgrades-migration-source-code-boundary` and reports a named coverage gap when its repository binding or required dependency is unavailable.
