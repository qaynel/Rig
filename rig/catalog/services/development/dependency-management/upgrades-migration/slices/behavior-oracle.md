# development.dependency-management.upgrades-migration - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming upgrades migration result from a real policy violation. It activates `upgrades-migration-source-code-boundary`, `upgrades-migration-dependency-management-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
