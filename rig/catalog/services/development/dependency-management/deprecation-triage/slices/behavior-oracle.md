# development.dependency-management.deprecation-triage - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming deprecation triage result from a real policy violation. It activates `deprecation-triage-source-code-boundary`, `deprecation-triage-dependency-management-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
