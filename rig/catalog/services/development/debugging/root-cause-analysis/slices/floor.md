# development.debugging.root-cause-analysis - slice floor + mutation-floor

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `floor` and `mutation-floor` slice establishes the lowest non-vacuous root cause analysis verdict for `source-code`. It activates `root-cause-analysis-source-code-boundary` and reports a named coverage gap when its repository binding or required dependency is unavailable.
