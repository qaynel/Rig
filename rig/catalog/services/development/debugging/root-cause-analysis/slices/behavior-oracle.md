# development.debugging.root-cause-analysis - slice behavior-oracle

Policy-grade generic baseline practice, not repository-tailored Context or Evidence coverage.

The `behavior-oracle` slice requires an example that distinguishes a conforming root cause analysis result from a real policy violation. It activates `root-cause-analysis-source-code-boundary`, `root-cause-analysis-debugging-context` and reports a named coverage gap when its repository binding or required dependency is unavailable.
