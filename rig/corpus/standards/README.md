# Standards

AI development standards that Rig enforces on itself and ships through the
corpus (subplan 07 owns the content). A standard is offered as enforced only
when the check that enforces it ships with it.

- `ai-sdlc.md` — what counts as evidence that something is done.
- `traceability.md` — one requirement, one acceptance criterion, one proving
  test, and the shipped validator that enforces it.
- `delivery-sop.md` — how a multi-step change is executed.
- `change-management.md` — the ordered sequence from a green gate to a
  published release, and the check that enforces it.
- `lint-format-setup.md`, `ecosystem-preferences.md` — repository setup rules.
