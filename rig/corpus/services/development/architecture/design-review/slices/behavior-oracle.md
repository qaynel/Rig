# development.architecture.design-review — behavior-oracle slice

Review interfaces and explicit tradeoffs against the intended outcomes. Resolve contradictory design assumptions before implementation instead of treating an approved diagram as proof of correctness.

Policy grade slice `design-review-slice-behavior-oracle`: List the interfaces under review by name. An empty list means no boundary was reviewed, so name each interface the change touches before implementation starts. Despite its name this slice is not a behavior oracle: it confirms interfaces, tradeoffs and an unresolved-tradeoff count are declared; it does not show that the review found the real design flaws.
