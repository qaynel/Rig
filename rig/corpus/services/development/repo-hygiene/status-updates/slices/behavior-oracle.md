# development.repo-hygiene.status-updates — behavior-oracle slice

Report observed progress, the work in flight and the next resolving action. Distinguish finished evidence from intended work so another contributor can resume accurately.

Policy grade slice `status-updates-slice-behavior-oracle`: List what is completed with evidence. Mixing intent with finished work misleads the reader, so record only done items. Despite its name this slice is not a behavior oracle: it confirms completed work, in-flight work and a next action are written; it does not show the status is accurate.
