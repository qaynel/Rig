# development.repo-hygiene.issue-pr-triage — floor and mutation-floor slice

Route issues using meaningful labels and an accountable owner. Closing a report needs a written disposition or proving fix; inactivity alone does not resolve the problem.

Policy grade slice `issue-pr-triage-slice-floor`: List the labels used to route issues. Unlabelled reports are not routed, so name the label set the repository uses.
