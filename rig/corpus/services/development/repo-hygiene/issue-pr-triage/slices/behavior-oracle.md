# development.repo-hygiene.issue-pr-triage — behavior-oracle slice

Route issues using meaningful labels and an accountable owner. Closing a report needs a written disposition or proving fix; inactivity alone does not resolve the problem.

Policy grade slice `issue-pr-triage-slice-behavior-oracle`: List the labels used to route issues. Unlabelled reports are not routed, so name the label set the repository uses. Despite its name this slice is not a behavior oracle: it confirms triage labels, owners and the close-without-disposition flag are declared; it does not show issues were actually triaged.
