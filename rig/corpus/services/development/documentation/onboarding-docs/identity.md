# development.documentation.onboarding-docs — identity

Offer when a new contributor cannot locate installation and execution instructions.

Policy grade. Offer contributor setup documentation when installation and execution instructions are hard to find.

Applicable surface: source-code. Owned scope: `documentation.onboarding-docs`. Input: `README.md` (text).

Disposition: executable. Native checks only match expected section headings.

The checks look for setup, run, and verification headings. They do not inspect the text below those headings or execute any commands.

The configured command examples in the catalogue are illustrative; choose setup and run instructions that match the repository.
