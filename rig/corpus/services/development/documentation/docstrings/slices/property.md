# development.documentation.docstrings — property-floor slice

Document the externally visible parameters and failure behavior of public symbols. A reader must be able to use the function without reconstructing its implementation.

Policy grade. `docstrings-slice-property-floor` confirms only that `documented_symbols` is configured. It does not assert a property of source declarations or documentation text.

Keep public parameter names and failure behavior aligned with their implementation. The declared symbol list provides a review scope, not evidence that the review occurred.
