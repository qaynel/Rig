# development.code-quality.code-review — behavior-oracle slice

Review the actual changed scope with independent ownership. At least one reviewer must resolve or explicitly disposition every finding before the change earns a clean review.

Policy grade slice `code-review-slice-behavior-oracle`: State the changed scope under review. A review without a scope may cover nothing, so list the files or diff range actually examined. Despite its name this slice is not a behavior oracle: it confirms review scope, reviewer count and the unresolved-findings setting are declared; it does not show the review was thorough.
